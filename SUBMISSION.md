### Maintainer notes

Video Trans provides local Whisper recognition and translated captions above fullscreen video. The README and user manual document installation, explicit isolated-runtime setup, removal, external dependencies, privacy and owned-resource cleanup. Setup is manual: Omarchy does not execute setup hooks. The plugin uses only user services for local translation; it preserves pre-existing services and loaded models. Online translation sends recognized text, not audio, to the configured endpoint. The MIT-licensed preview contains synthetic example captions. Please review the installer, dependency-management and user-service capabilities reported by the baseline.
